Twin Cities Animal Rescue Website

Files to open:
- index.html = Home page
- services.html = Services page
- about.html = About page
- contact.html = Contact page
- styles.css = Site styling

How to preview:
1. Open the folder.
2. Double-click index.html.
3. The site will open in your browser.
4. Test Home, Services, About, and Contact links.

For GitHub:
Upload every file in this folder to the same repository so images, video, HTML, and CSS stay linked correctly.
